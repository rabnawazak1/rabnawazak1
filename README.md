### 🔭 What I'm building

- **Rabixx ERP** — a modular, domain-driven ERP covering Sales, Purchasing, Inventory, a double-entry Ledger, and CRM, built on Laravel 13 + Vue/Inertia. → [Overview](https://github.com/rabnawazak1/rabixx-erp)
- **RabixxCRM** — an Android field-agent app (Flutter) that pairs with the ERP's mobile API so sales agents can manage leads and follow-ups on the move. → [Overview](https://github.com/rabnawazak1/rabixx-crm)

### 📦 Open-source packages

| Package | What it does |
|---|---|
| [**laravel-ddd-generator**](https://github.com/rabnawazak1/laravel-ddd-generator) | An Artisan command that scaffolds a full Domain-Driven-Design module (Actions, Controller, Requests, Service, Repository, Model, DTO) in one line. |
| [**laravel-custom-softdelete**](https://github.com/rabnawazak1/laravel-custom-softdelete) | Soft deletes with a real audit trail — `is_deleted`, `deleted_at`, and `deleted_by` — so you know *who* removed a record, not just *when*. |
